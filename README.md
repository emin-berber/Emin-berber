## ✦ Supabase Entegrasyonu ve Gerçek Zamanlı Slot Kilitleme (Real-Time Slot Locking)

### 1. Supabase CDN
Sayfanın `<head>` bölümüne Supabase JavaScript SDK CDN'i eklenmiştir:
```html
<script src="https://cdn.jsdelivr.net/npm/@supabase/supabase-js@2"></script>
```

### 2. İstemci Başlatma (Client Initialization)
[app.js](file:///c:/Users/proggress/Desktop/project/app.js) içerisinde `SUPABASE_URL` ve `SUPABASE_ANON_KEY` yer tutucuları net ve anlaşılır şekilde tanımlanmıştır:
```javascript
const SUPABASE_URL = 'https://YOUR_SUPABASE_PROJECT_REF.supabase.co';
const SUPABASE_ANON_KEY = 'YOUR_SUPABASE_ANON_KEY';
```
> **Not:** Kullanıcı anahtarlarını henüz girmemiş olsa dahi uygulama çökmez; otomatik olarak yerel önbellek simülasyonu ile çalışmaya devam eder ve konsolda rehberlik mesajı görüntüler.

### 3. Berbere Özgü Gerçek Zamanlı Slot Kilitleme (Barber-Specific Slot Locking)
- Kullanıcı bir berber (**Ahmet Usta**, **Mehmet Usta** veya **Fark Etmez**) ve tarih seçtiğinde, Supabase `randevular` tablosu canlı olarak sorgulanır.
- Seçilen berber için o gün alınmış tüm saatler arayüzde **anında devre dışı bırakılır (gri ve üzeri çizili - Dolu)**.
- **Kritik Kural:** Slot kilitleme kesinlikle berbere özeldir. Örneğin, Ahmet Usta için saat 11:00 randevusu alındığında Mehmet Usta'nın saat 11:00 slotu açık kalmaya devam eder!
- Supabase **Realtime** aboneliği sayesinde başka bir cihazdan randevu alındığında açık olan tüm sayfalarda saatler sayfa yenilenmeden anında kilitlenir.

### 4. Randevu Kaydı & Doğrulama (Booking Submission & Validation)
- Aynı berber, gün ve saat için mükerrer randevu gönderimi hem istemci tarafında hem de veritabanı kısıtlaması (`UNIQUE(berber_adi, tarih, saat)`) ile engellenir.
- **Ad Soyad** ve geçerli **Telefon Numarası** (`0 (5XX) XXX XX XX`) zorunludur.
- **Mükerrer Telefon Numarası Kontrolü (Duplicate Phone Number Check):**
  - Kullanıcı formu doldurup "Randevuyu Onayla" butonuna bastığında, Supabase `randevular` tablosunda girilen telefon numarası taranır.
  - Bu telefon numarası ile kayıtlı bir randevu veritabanında **zaten varsa**, randevu oluşturma anında engellenir ve ekranda `"Bu telefon numarası ile zaten aktif bir randevunuz bulunmaktadır."` uyarısı gösterilir.
  - Telefon veritabanında **yoksa**, normal akış devam eder: randevu Supabase'e eklenir, ilgili saat dilimi kilitlenir ve WhatsApp onay bağlantısı açılır.

- Kullanıcı **"Randevuyu Onayla"** butonuna bastığında:
  1. Randevu Supabase `randevular` tablosuna eklenir (`berber_adi`, `tarih`, `saat`, `musteri_adi`, `telefon`).
  2. Kayıt başarılı olduğunda arayüzde o saat dilimi anında kilitlenir.
  3. Kuaför salonu sahibine bildirim gitmesi için `+905526699597` numarasına önceden biçimlendirilmiş WhatsApp mesajı yeni sekmede açılır.

## ✦ Supabase SQL Kurulum Tablosu (5 Saniyede Kurulum)

Supabase Dashboard -> **SQL Editor** sayfasına gidip [supabase_schema.sql](file:///c:/Users/proggress/Desktop/project/supabase_schema.sql) dosyasındaki kodu çalıştırabilirsiniz:

```sql
create table if not exists public.randevular (
  id bigint generated by default as identity primary key,
  berber_adi text not null,
  tarih text not null,
  saat text not null,
  musteri_adi text not null,
  telefon text not null,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  constraint unique_berber_tarih_saat unique (berber_adi, tarih, saat)
);

-- Realtime özelliğini açma:
alter publication supabase_realtime add table public.randevular;

-- Row Level Security (RLS) politikaları:
alter table public.randevular enable row level security;

create policy "Randevular herkes tarafından okunabilir"
  on public.randevular for select using (true);

create policy "Randevular herkes tarafından eklenebilir"
  on public.randevular for insert with check (true);
```
